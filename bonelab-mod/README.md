# ClipLink Media for BONELAB

ClipLink Media is a Windows PC MelonLoader code mod for the mod.io **Media Players!** content pack.

## Use

1. Open `ClipLink Media` in BoneMenu and choose **Open YouTube**.
2. Copy a YouTube video URL.
3. Return to BONELAB and spawn any Media Player from the installed `Elijoe.MediaPlayer` pack.
4. Hold the Media Player and press **B**.
5. The mod downloads an MP4 with `yt-dlp`, caches it, and plays the local file automatically.

The **Download copied link** BoneMenu button can pre-download the clipboard video. Press B on a Media Player afterward to play the cached copy instantly.

## Installation

Copy the ZIP contents into the BONELAB installation folder. The package contains:

- `Mods/ClipLinkMedia.dll`
- `UserData/yt-dlp.exe` (the mod also detects Thunderstore's team/package installation folder)

Required: MelonLoader, BoneLib, and the mod.io `Elijoe.MediaPlayer` content mod.

Only download videos you own or have permission to use. YouTube account-only, DRM-protected, age-restricted, or unavailable videos may fail.
